# Hostel Management System — DBMS Project

This repository contains the **Hostel Management System** project developed as part of our **Database Management Systems** coursework. The project focuses on modernizing hostel management by digitizing conventional file-based registries and processes using **MySQL** and **PL/SQL**.

## 📄 Project Report

All the project documentation, SQL/PLSQL code, ER diagrams, and output screenshots are available in this repository.

## 📌 Project Overview

The Hostel Management System manages three major departments:

-  **Complaint Department**
-  **Mess Department**
-  **Laundry Department**

The system allows storage, management, and retrieval of data related to hostel students and services, enhancing efficiency and accessibility.

## ⚙ Features Implemented

- **Database Design**  
  ER Diagram and relational schema for hostel management.

- **Database Normalization**  
  Normalized schema to 1NF.

- **SQL & PL/SQL Operations**  
  - Table creation queries
  - Data insertion queries
  - Stored Procedures
  - Functions
  - Triggers
  - Exception Handling
  - Cursors

- **Snapshots of Outputs**  
  Sample outputs and results of executed queries and PL/SQL commands.

## 🛠️ Technologies Used

- **Database:** MySQL
- **Languages:** SQL, PL/SQL
